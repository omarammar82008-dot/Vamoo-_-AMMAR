VAMOO — منصة تعلّم الإسبانية

محتويات الحزمة:
- index.html: الموقع التفاعلي كاملًا في ملف واحد.
- netlify.toml: إعدادات نشر الموقع كصفحة ثابتة.

المزايا الموجودة في النسخة الحالية:
- واجهة عربية متجاوبة للموبايل والكمبيوتر.
- مستويات ودروس إسبانية، قاموس إسباني-عربي.
- اختبارات قصيرة وتصحيح فوري ونقاط وتقدم.
- تشغيل نطق الكلمات، وتدريب صوتي بحسب دعم المتصفح.
- تسجيل دخول تجريبي وحفظ محلي للتقدم على نفس الجهاز والمتصفح.
- واجهة Freemium / PLUS تجريبية.

تشغيل محلي:
افتح index.html في متصفح حديث. بعض ميزات الميكروفون تتطلب HTTPS أو localhost.

النشر للحصول على رابط عام:
1. افتح https://app.netlify.com/drop
2. فك ضغط ملف VAMOO.zip على جهازك.
3. اسحب مجلد VAMOO الذي يحتوي index.html إلى صفحة Netlify Drop.
4. انتظر النشر، ثم انسخ الرابط الذي ينشئه Netlify.

حدود مهمة قبل استخدام الموقع تجاريًا:
- تسجيل الحسابات الحالي تجريبي ومحلي، وليس نظام حسابات آمنًا.
- التقدم محفوظ على نفس المتصفح والجهاز فقط.
- لا توجد قاعدة بيانات أو مزامنة بين الأجهزة.
- PLUS لا يجمع أموالًا حقيقية؛ بوابة الدفع غير مفعلة.
- يلزم إعداد Backend ومصادقة وقاعدة بيانات وبوابة دفع بحسابات المالك قبل إطلاق اشتراكات حقيقية.
